# Flashcards Offline

The active product is the standalone Android offline app in [offline-app/](offline-app/).

- No account, backend, cloud sync, or internet permission
- On-device IndexedDB storage inside a bundled Android WebView
- SM-2 spaced repetition, decks, study progress, and JSON backups
- Version 2 backup export with version 2 and 3 import support

See [offline-app/README.md](offline-app/README.md) for features, tests, security boundaries, and APK build instructions.

The other archives, blueprint, and audit documents at the repository root are retained as historical reference material. They are not runtime dependencies and are not combined into this application.
